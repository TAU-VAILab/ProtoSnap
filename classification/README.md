# Sign classification experiment (Table 2)

This folder documents the sign classification experiment from Section 5.2 / Appendix A.7 of the paper: a ResNet-18 trained on real CSDD crops, with and without additional images generated by our models.

## Data split

Sign crops come from the [Cuneiform Sign Detection Dataset (CSDD)](https://github.com/CompVis/cuneiform-sign-detection-dataset) (Dencker et al., 2020). We use its official tablet-level train/test partition:

- **Train** (`csdd_train.csv`): all annotated signs on the CSDD train tablets whose images we could download: 3,300 crops (paper uses 3,299), 38 tablets, 223 classes.
- **Test** (`csdd_test.csv`): annotated signs on the CSDD test tablets, **restricted to classes that appear in the train set**: 2,906 crops, 30 tablets, 180 classes.

Each row points to an annotation in the CSDD repository: `annotation_file` (`bbox_annotations_{train,test}_full.csv` in CSDD's `annotations/` folder) and `annotation_row` (0-based data-row index in that file), along with the tablet, MZL label, and bounding box. Crops are taken from the tablet photographs using `bbox`. Classes are MZL labels.

Some CSDD tablet images are hosted externally (e.g. the British Museum and CDLI), and their URLs may stop working, so newer downloads may cover fewer tablets than listed here.

## Training

- ResNet-18, ImageNet-initialized; Adam, learning rate 1e-3, batch size 64.
- **Real data only:** 10 epochs on the train split.
- **With generated data (+SD / +CN):** train on real + generated images, then fine-tune for 10 epochs on real data only (see Appendix A.7). Generated images for +CN come from `gen_images_with_cn.py`.

## Results

| Training data | Accuracy (all) | Accuracy (rare) | Balanced acc. (all) | Balanced acc. (rare) |
|---|---|---|---|---|
| CSDD | 58.43% | 25.84% | 34.57% | 16.45% |
| + SD data | 61.56% | 38.56% | 39.02% | 31.13% |
| + CN data | 64.14% | 53.17% | 43.57% | 39.98% |

Rare signs are those with fewer than 50 occurrences in the real train set.

`cn_run_predictions.csv` contains the test-set predictions of the +CN run (`y_true`, `y_pred` as integer class indices), which give 64.14% accuracy and 43.57% balanced accuracy.
